# Life Manager

## Product Vision

Life Manager is a personal operating system for everyday life.
It helps users organize tasks and routines, understand what needs to be done today, and track their weekly progress.

The goal is to reduce planning effort, avoid procrastination, and provide a clear overview of everyday responsibilities.

## Primary User Goal

The user wants to quickly understand what needs to be done today, complete tasks, and see how they are progressing throughout the week.

## Core User Flow

Manage tasks → Complete today's tasks → Check weekly progress

## Core Product Areas

- Dashboard / Today
- Tasks
- Recurring Tasks
- Weekly Overview
- Progress
- User Account / Profile
- Settings

## Product Principles

- Keep everyday planning simple.
- Make today's priorities immediately visible.
- Recurring tasks should require minimal manual planning.
- Progress should be understandable at a glance.
- Functionality comes before visual polish.
- Avoid unnecessary complexity.
